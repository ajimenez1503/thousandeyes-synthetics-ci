# Security policy

## Report a vulnerability

Report suspected vulnerabilities in ThousandEyes Synthetics CI to [oss-security@cisco.com](mailto:oss-security@cisco.com). This is Cisco's open-source security reporting channel, coordinated by the Open Source Program Office and the Product Security Incident Response Team (PSIRT).

Do not disclose suspected vulnerabilities in public GitHub issues, discussions, or pull requests. Use the email channel above rather than GitHub private vulnerability reporting.

Include the following information when available:

- The affected runner version or source commit and operating system.
- Whether the issue affects the runner, Action, bundled CLI backend, or a dependency.
- A description of the security impact and steps to reproduce it.
- A minimal reproduction with synthetic targets and credentials.
- Known mitigations and whether you are aware of active exploitation.

Do not send production tokens or unrelated personal or customer data. The security team may request additional information through the private reporting process.

## Handling reports

Cisco's security process coordinates assessment, affected-version analysis, remediation, and disclosure with project maintainers. Maintainers who receive a suspected vulnerability report must forward it promptly to [oss-security@cisco.com](mailto:oss-security@cisco.com) or [psirt@cisco.com](mailto:psirt@cisco.com).

For ordinary bugs and feature requests, use the repository's issue templates. Suggestions about this policy can be submitted in a pull request without including vulnerability details.
